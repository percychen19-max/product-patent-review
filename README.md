# 产品专利评估

给做跨境电商和产品开发的团队使用。发一张自家样机图、两个备选设计或一个竞品链接，让能检索专利的 AI 回答一个实际问题：**这款在目标市场可以继续推进、要先改哪里，还是需要补哪项证据才能定稿？**

## 怎么给自己的 AI 用

把本仓库地址和产品图一起发给 AI，再复制这句话：

> 请按这个仓库首页的评估方法，评估我发的产品。先给我一句可转发的建议，再列出影响结论的专利号、关键图号或权利要求，以及官方来源。没有写市场时，先按美国站评估。

如果只想发群，可以加上“只给一句话”。发的是竞品时，标上“竞品”；要做其他市场时，写上国家或地区。图片、视频、设计图、产品链接、ASIN 或专利号都可以作为起点。

可以把[本页完整 Markdown 原文](https://raw.githubusercontent.com/percychen19-max/product-patent-review/main/README.md)单独发给 AI，也可以下载后作为附件上传。使用 Codex 的团队可以直接打开下载或克隆的仓库，在项目中新建对话发产品图，随项目提供的[评估技能](.agents/skills/product-patent-review/SKILL.md)会指引评估。

## AI 收到产品后如何评估

1. **确定评估对象。** 写明是自家实拍、拟改设计还是竞品，标明版本、目标市场和检索日期。同一张照片有两个版本时，用图上能看见的特征指明推荐哪款。只有竞品链接时，可以查竞品的权利线索；比较自家款时还需要相应的自家资料。
2. **检索目标市场公开权利。** 从品类及同义词、关键形态或结构、竞品品牌及权利人、分类号入手。沿最接近的文件查看引证和同族，核实权利是否覆盖销售地。区分申请公开、已授权和评估日可查的法律状态。供应商声明、平台在售和检索相似分数只能作为线索。
3. **做外观比对。** 打开重点专利的授权原图，选与产品相同的视角并排比较。按该专利的说明识别主张和排除的部分，记录图号。美国外观评估关注熟悉已有设计的普通观察者所见的整体印象。说明真正拉开差异的位置，并指出最接近的地方。其他市场采用当地标准。
4. **需要时核对技术结构。** 阅读与该产品相关的授权独立权利要求，把每个必要条件和可核实的产品事实对应起来。分别检查相关独立项和同族授权。单张正面图通常只能判断看得见的部分；若某个内部结构会改变开模决定，明确索取哪张截面图、装配图或运行证据。
5. **给出可执行的决定。** 先回答“哪个版本可以定稿”“建议改哪一处”或“哪一步应暂缓”，再说明适用的市场、版本、检索范围及会改变判断的条件。证据不足时明确该项未知；外观已可判断、结构仍待确认时，分别说明。若问题是申请自家专利，改查申请日前已有设计和产品公开，并把可申请性与销售风险分别回答。

## 交付内容

- **一句可转发的结论**，写明推荐版本和下一步动作。用户只要一句时，到这里即可。
- **一份精简中文 PDF**，首页给结论，正文放样机与授权图或必要要素对照，附最接近的专利号、关键视图或权利要求、来源和未确认项。若工具无法生成 PDF，交付可导出的完整报告正文。
- **来源与证据边界**，写清哪些原图或授权文本已实际打开。AI 无法联网时，可以分析照片、列检索线索，或请用户上传官方授权书；未完成的核查须标为待核。未公开的样机留在用户授权的环境内。

## 美国官方资料

从 [USPTO Patent Public Search](https://www.uspto.gov/patents/search/patent-public-search) 检索授权和公开申请，使用 [Patent Center](https://www.uspto.gov/patents/apply/patent-center) 查看可访问的审查档案。核对授权图时参考 [USPTO 外观专利图式指南](https://www.uspto.gov/patents/basics/apply/design-patent)。对专利权的性质和侵权争议处理，可查 [USPTO 官方说明](https://www.uspto.gov/patents/basics/manage)。[美国专利检索与核对入口](.agents/skills/product-patent-review/references/us-sources.md)收录了授权书 PDF 路径、维持费查询和判例。

输出属于所查范围内的产品专利初评。涉及重大量产投入且仍有实质争议时，指出需要当地专利律师解决的具体问题。
