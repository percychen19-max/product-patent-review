# 美国数据入口与复核方法

- [USPTO Patent Public Search](https://www.uspto.gov/patents/search/patent-public-search) 用于查授权与申请公开。由专利号开始时，再沿发明人／设计人、权利人、分类和引证检索；有多种品类名称时兼查相邻品类。商品页的专利标记能帮助关联权利人，仍需打开官方原文。
- 授权书 PDF 可尝试官方地址 `https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/<号码>`。美国实用专利用纯数字，外观用 D 加数字，去掉逗号与 S1/B2 等种类码。务必打开核对首页号码和图页，下载失败时从 Patent Public Search 进入。扫描 PDF 可能提不出文字，要渲染图页核对线型、图号和权利说明。若使用授权书镜像，准确注明来源。
- [USPTO Patent Center](https://www.uspto.gov/patents/apply/patent-center) 可查申请、审查档案及关联申请；[USPTO 维持费信息](https://www.uspto.gov/patents/maintain) 用于适用的美国实用专利。区分授权事实和评估日效力。不要因没有外观维持费记录即判断已失效。临时查不到档案，没有依据的字段标为未核实。
- [USPTO 外观申请与图式指南](https://www.uspto.gov/patents/basics/apply/design-patent)；[联邦巡回上诉法院对整体视觉印象和排除部分的说明，第 12–13 页](https://www.cafc.uscourts.gov/opinions-orders/24-2191.OPINION.7-17-2025_2546100.pdf)。虚线的含义取自该份授权书。专利的放大图有助于定位细节，不能把放大的零件单独视为整件权利范围。
- [USPTO 对授权、再审及侵权问题的说明](https://www.uspto.gov/patents/basics/manage)。申请自己的专利和排查第三方权利按不同问题处理；向官方公开库查档不会产生对该产品的不侵权裁定。另见 [MPEP 1120 的申请公开范围](https://www.uspto.gov/web/offices/pac/mpep/s1120.html)。
